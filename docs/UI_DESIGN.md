# API Tester - UI 设计文档

## 1. 设计原则

- **简洁优先**：核心操作不超过 2 步到达
- **平台一致**：Android / Windows 统一视觉语言，交互各自适配
- **内容为王**：请求编辑和响应展示占据最大视觉权重

## 4. 核心页面职责

### 4.1 请求编辑页

| 区域         | 内容                                     |
| ---------- | -------------------------------------- |
| 顶部栏        | 方法选择器 + URL 输入框 + 发送按钮                 |
| 配置 Tab     | Params / Headers / Body / Auth / Tests |
| Body 子 Tab | JSON / Form / Raw / Binary             |
| 响应区        | 状态码 + 耗时 + 大小 + Body 查看器 + Headers     |
| 底部操作       | 保存到集合 / 从集合加载                          |

### 4.2 集合列表页

| 区域  | 内容                |
| --- | ----------------- |
| 顶部栏 | 集合名称 + 新建按钮       |
| 列表  | 文件夹 / 请求混排，图标区分类型 |
| 空态  | 引导用户创建第一个集合       |

### 4.3 环境管理页

| 区域       | 内容          |
| -------- | ----------- |
| 环境切换器    | 下拉选择当前激活环境  |
| 变量列表     | 键值对表格，支持增删改 |
| 全局变量 Tab | 独立于环境的通用变量  |

### 4.4 我的页面

| 区域   | 内容             |
| ---- | -------------- |
| 账号信息 | 头像 + 昵称 + 邮箱   |
| 同步状态 | 上次同步时间 + 同步按钮  |
| 设置入口 | 主题 / 数据管理 / 关于 |

## 5. 重要组件

### 5.1 请求方法选择器

```
┌──────┐
│ GET ▼│  ← 下拉菜单，颜色编码
└──────┘
```

- 下拉选项带方法颜色标记
- 选中后标签显示对应颜色

### 5.2 键值对编辑器

```
┌──────────────────────────────────────┐
│ ✓  Key              Value        🗑  │
│ ✓  Content-Type     application/json │
│ ✓  Authorization    Bearer xxx       │
│    + 添加参数                          │
└──────────────────────────────────────┘
```

- 每行：启用开关 + Key 输入 + Value 输入 + 删除按钮
- 底部添加按钮
- 支持从 cURL / JSON 导入

### 5.3 JSON 编辑器

```
┌──────────────────────────────────────┐
│ {                                    │
│   "name": "test",                   │
│   "value": 123                      │
│ }                                    │
│ ────────────────────────────────     │
│ 行号 | 语法高亮 | 自动格式化         │
└──────────────────────────────────────┘
```

- 行号显示
- 语法高亮（key/value/字符串/数字/布尔）
- 一键格式化 / 压缩
- 错误位置提示

### 5.4 响应查看器

```
┌──────────────────────────────────────┐
│ 200 OK    128ms    2.3KB            │
│ [Body] [Headers] [Tests]            │
│ ────────────────────────────────     │
│ {                                   │
│   "status": "success",             │
│   "data": { ... }                  │
│ }                                   │
│                          🔍 搜索    │
└──────────────────────────────────────┘
```

- 状态码颜色编码
- Tab 切换 Body / Headers / Tests
- Body 支持 JSON 格式化 / 原始文本
- 搜索关键词高亮

### 5.5 集合树节点

```
📁 用户管理
│   📁 认证
│   │   └── POST /login
│   │   └── POST /register
│   └── GET /profile
└── 📁 订单
    └── GET /orders
```

- 文件夹图标 + 折叠/展开
- 请求显示方法色标签 + 路径
- 长按/右键菜单：重命名、删除、移动

### 5.6 环境变量表

```
┌──────────────────────────────────────┐
│ 环境: [开发环境 ▼]    [全局变量]     │
│ ────────────────────────────────     │
│ ✓  baseUrl      http://dev.api.com  │
│ ✓  token        eyJhbG...           │
│    timeout      30000               │
│    + 添加变量                         │
└──────────────────────────────────────┘
```

### 5.7 同步状态指示器

| 状态  | 显示             |
| --- | -------------- |
| 已同步 | 绿色圆点 + "已同步"   |
| 同步中 | 蓝色旋转图标 + "同步中" |
| 离线  | 灰色圆点 + "离线"    |
| 冲突  | 黄色三角 + "有冲突"   |

## 6. 交互模式

### 6.1 Android

| 手势   | 操作        |
| ---- | --------- |
| 左滑   | 删除列表项     |
| 下拉   | 刷新集合/历史   |
| 长按   | 打开上下文菜单   |
| 双指缩放 | JSON 响应缩放 |

### 6.2 Windows

| 操作   | 快捷键        |
| ---- | ---------- |
| 新建请求 | Ctrl+N     |
| 保存   | Ctrl+S     |
| 发送请求 | Ctrl+Enter |
| 搜索   | Ctrl+F     |
| 切换环境 | Ctrl+E     |

## 7. 响应式布局断点

| 断点      | 宽度        | 布局          |
| ------- | --------- | ----------- |
| Mobile  | < 600px   | 单列，底部导航     |
| Tablet  | 600-900px | 可折叠侧边栏      |
| Desktop | > 900px   | 固定侧边栏 + 内容区 |

## 8. 组件规范

### 8.1 间距

| 类型    | 值                 |
| ----- | ----------------- |
| 页面边距  | 16px              |
| 卡片内边距 | 12px              |
| 列表项间距 | 8px               |
| 元素间距  | 8px / 12px / 16px |

### 8.2 圆角

| 元素  | 圆角   |
| --- | ---- |
| 卡片  | 12px |
| 按钮  | 8px  |
| 输入框 | 8px  |
| 标签  | 4px  |

### 8.3 字体

| 用途     | 字号   | 字重       |
| ------ | ---- | -------- |
| 页面标题   | 20sp | Bold     |
| 区块标题   | 16sp | SemiBold |
| 正文     | 14sp | Regular  |
| 辅助文字   | 12sp | Regular  |
| 代码/URL | 13sp | Mono     |

### 8.4 图标

- 风格：线性图标（Outlined）
- 尺寸：24dp（标准）/ 20dp（紧凑）/ 32dp（强调）
- 推荐图标库：`lucide_icons` 或 `heroicons`
